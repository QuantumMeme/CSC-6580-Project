## Project Overview

This project focuses on developing a Python-based program analysis tool for examining compiled software. The tool will analyze Executable and Linkable Format (ELF) files on Linux systems using the AMD64 architecture.

Throughout the semester, the project will evolve through a series of assignments, introducing different techniques for analyzing and understanding compiled executable code.

## Technologies

- **Language:** Python 3.14.4+
- **Platform:** Linux (AMD64)
- **Libraries:**
  - [Capstone](https://www.capstone-engine.org/) – Disassembly framework
  - [pyelftools](https://github.com/eliben/pyelftools) – ELF file parsing and analysis
